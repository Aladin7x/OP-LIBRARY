# Viết Prompt Template tái sử dụng cho workflow riêng

## Mục tiêu
Biến 1 dạng prompt bạn hay gõ lại từ đầu mỗi lần thành 1 template có placeholder, dùng lại được trong dưới 1 phút mỗi lần, thay vì mất vài phút soạn lại và dễ quên mất phần quan trọng.

## Khi nào dùng
- Nhận ra mình đang gõ lại 1 dạng prompt tương tự từ 3 lần trở lên
- Prompt đó có cấu trúc lặp lại rõ ràng (vai trò, bối cảnh, yêu cầu, định dạng), chỉ khác nhau ở dữ liệu đầu vào mỗi lần
- Muốn chuẩn hoá chất lượng output giữa các lần dùng, tránh việc Claude trả lời khác kiểu chỉ vì bạn viết prompt hơi khác nhau mỗi lần
- KHÔNG cần làm bước này nếu task chỉ làm đúng 1 lần hoặc luôn đòi hỏi tư duy hoàn toàn mới mỗi lần

## Input
- 2-3 ví dụ prompt bạn đã từng viết tay cho cùng 1 loại việc
- Output bạn hài lòng nhất trong số các ví dụ đó (nếu có), để làm chuẩn tham chiếu
- Ghi chú phần nào trong prompt bạn hay phải sửa lại nhất mỗi lần dùng — đó chính là chỗ cần biến thành placeholder

## Prompt Template
```
Bạn là trợ lý giúp tôi khái quát hoá 1 dạng prompt tôi hay dùng lặp lại thành 1 template tái sử dụng.

Đây là 2-3 prompt tôi đã từng viết tay cho cùng 1 loại việc:

Ví dụ 1:
{{dán prompt cũ 1}}

Ví dụ 2:
{{dán prompt cũ 2}}

Ví dụ 3 (nếu có):
{{dán prompt cũ 3}}

Phần tôi hay phải sửa lại nhất mỗi lần dùng: {{liệt kê, vd: tên khách hàng, chủ đề, độ dài mong muốn}}

Yêu cầu:
1. Rút ra cấu trúc chung của các prompt trên: phần nào luôn giữ nguyên, phần nào luôn thay đổi.
2. Viết thành 1 prompt template hoàn chỉnh, dùng placeholder dạng {{tên_rõ_nghĩa}} cho các phần thay đổi.
3. Giữ nguyên phần vai trò/bối cảnh/yêu cầu/định dạng đã chứng minh hiệu quả từ các ví dụ tôi đưa.
4. Viết kèm 1 dòng mô tả: template này dùng khi nào, không dùng khi nào.

Định dạng output: template trong code block, kèm 1 ví dụ điền mẫu minh hoạ ngay bên dưới.
```

## Checklist
- [ ] Đã có ít nhất 2-3 ví dụ thực tế trước khi khái quát hoá, không viết template chỉ từ 1 lần dùng duy nhất
- [ ] Đã test template với ít nhất 2 bộ dữ liệu khác nhau để chắc nó thực sự tổng quát được
- [ ] Đặt tên placeholder rõ nghĩa (`{{ten_khach_hang}}` chứ không phải `{{x}}` hay `{{a}}`)
- [ ] Đã lưu template vào nơi dễ tìm lại (file riêng, Notion, hoặc Claude Project knowledge)
- [ ] Đã ghi 1 dòng chú thích ngắn về khi nào nên dùng template này

## Expected Output
1 file prompt template (`.md` hoặc `.txt`) có đủ phần vai trò/bối cảnh/yêu cầu/định dạng rõ ràng, placeholder đặt tên nhất quán, kèm 1 dòng mô tả use case và 1 ví dụ điền mẫu minh hoạ. Template tốt là template bạn có thể đưa cho chính mình 3 tháng sau và vẫn hiểu ngay cách dùng mà không cần đọc lại giải thích dài dòng.

## Common mistakes
- Khái quát hoá quá sớm chỉ từ 1 lần dùng duy nhất — template ra đời cứng nhắc, không hợp với các trường hợp khác ngoài lần đó
- Đặt quá nhiều placeholder (trên 8-10) khiến việc điền template mất thời gian hơn cả viết tay từ đầu
- Không test lại template sau khi tạo xong — để lỗi cấu trúc (thiếu ngữ cảnh, yêu cầu mơ hồ) âm thầm tồn tại nhiều lần dùng sau
- Lưu template rải rác nhiều nơi (note app, đoạn chat cũ, file Word riêng) rồi quên mất mình đã có sẵn, lại viết tay từ đầu
- Không cập nhật template khi cách làm việc đã thay đổi, tiếp tục dùng bản cũ đã lỗi thời mà không nhận ra

## Phiên bản Claude Code
Workflow này chủ yếu dùng Claude Chat vì bản chất là soạn thảo và tinh chỉnh prompt qua tương tác. Nếu bạn dùng Claude Code thường xuyên, có thể lưu các template hay dùng trực tiếp vào cuối file `CLAUDE.md` của project (phần "Prompt templates tôi hay dùng") để Claude Code tự nhớ ngữ cảnh mỗi khi mở project đó. Nếu template đủ phức tạp và dùng lặp lại như 1 quy trình chuẩn nhiều bước, cân nhắc đóng gói thành 1 skill riêng trong `.claude/skills/<ten-skill>/SKILL.md` — lúc đó chỉ cần gõ `/ten-skill` thay vì copy-paste template thủ công mỗi lần.

## Khi nào nên dùng Deep Research
Gần như không cần — đây là việc tự phản chiếu lại cách chính bạn đã làm việc qua các ví dụ thật, không phải câu hỏi cần tổng hợp thông tin bên ngoài. Deep Research chỉ hữu ích nếu bạn muốn khảo sát cách nhiều người khác cấu trúc prompt template cho cùng 1 loại việc để lấy thêm ý tưởng tham khảo, nhưng đây là bước tuỳ chọn, không bắt buộc cho quy trình cốt lõi của workflow này.
